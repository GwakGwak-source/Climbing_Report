# 클라이밍 정모 리포트

소모임에 공개된 클라이밍 모임의 정모 일정을 매일 모아서, 암장별·시간대별(낮클/퇴근클)로 정리한 한 장짜리 페이지를 만듭니다.
지도는 Leaflet + OpenStreetMap이라 API 키가 없어도 됩니다.

```
python main.py                # 수집 + docs/index.html 생성
python main.py --max 40       # 요청 수를 줄여서 빠르게 시험
python main.py --render-only  # 마지막 수집 결과로 페이지만 다시 생성 (gyms.json 고친 뒤 확인용)
```

Python 3.10 이상, 외부 패키지 없음.

## 동작 방식

1. **모임 찾기**: `config.json`의 `seed_pages`(소모임 검색·지역 페이지)에서 클라이밍 모임을 모읍니다.
   소모임의 클라이밍 관심사 코드(`18007`)나 모임 이름·소개에 클라이밍 관련 단어가 있으면 클라이밍 모임으로 봅니다.
2. **넓히기**: 모임 페이지의 '비슷한 모임'을 따라가며 새 클라이밍 모임을 찾습니다(`crawl_similar`).
   찾은 모임은 `data/groups.json`에 쌓이므로 날마다 목록이 늘어납니다. 60일 동안 정모가 없으면 뺍니다.
3. **정모 읽기**: 모임 페이지에 공개된 정모 일정(날짜·시간·장소·참석/정원)을 읽습니다. 멤버 이름 같은 개인 정보는 저장하지 않습니다.
4. **암장 묶기**: `gyms.json` 사전으로 '논현 더클라임', '논더클', '더클라임 논현점'을 모두 `더클라임 논현`으로 묶고 좌표를 붙입니다.
5. **페이지 만들기**: `docs/index.html`, `docs/reports/날짜.html`, `docs/archive.html`을 씁니다.

요청은 1초 간격, 한 번 실행에 최대 300회입니다(`request_delay_sec`, `max_requests`).
소모임 robots.txt가 허용하는 공개 HTML 페이지만 읽고, 내부 API는 쓰지 않습니다.

## 다른 지역 추가하기

`config.json`에서 두 군데를 고칩니다.

```json
"regions": ["서울특별시", "경기도", "부산광역시"],
"seed_pages": [ ..., "/부산-클라이밍-모임", "/부산-서면-클라이밍-모임" ]
```

- `regions`: 리포트에 넣을 광역시·도 이름(정식 명칭). 비워 두면(`[]`) 전국.
  두 곳 이상이면 페이지 위에 `경기권 / 서울권`처럼 지역 탭이 생기고, 첫 번째 지역이 기본 탭입니다.
  `index.html#서울`처럼 주소 끝에 지역 이름을 붙이면 그 탭으로 바로 열립니다.
- `seed_pages`: 그 지역 모임을 찾기 시작할 페이지. 소모임에 있는 지역 페이지는
  `/부산-클라이밍-모임`, `/대전-클라이밍-모임`, `/대구-클라이밍-모임`, `/인천-클라이밍-모임`, `/수원-클라이밍-모임`,
  `/강남-클라이밍-모임`, `/홍대-클라이밍-모임`, `/부산-서면-클라이밍-모임`, `/대전-둔산-클라이밍-모임` 입니다.
- 특정 모임을 꼭 넣고 싶으면 `extra_groups`에 모임 주소를 넣으세요: `"extra_groups": ["https://www.somoim.co.kr/<모임id>"]`

지역이 늘면 모임 수도 늘어나니 `max_requests`도 함께 올려 주세요(모임 1곳 = 요청 1회).

## 암장 추가하기 (지도에 표시)

실행 끝에 `사전에 없는 장소` 목록이 나옵니다. 이 장소들은 목록에는 나오지만 지도에는 없습니다.

- **직접 추가**: `gyms.json`에 브랜드와 지점, 좌표를 넣습니다. 좌표는 카카오맵·네이버지도에서 장소를 우클릭하면 복사할 수 있습니다.
  ```json
  {"brand": "락트리클라이밍", "brand_aliases": ["락트리"],
   "gyms": [{"branch": "수내", "branch_aliases": ["수내", "분당"], "region": "경기도", "lat": 0.0, "lng": 0.0}]}
  ```
- **자동 검색**: 카카오 개발자 콘솔의 REST API 키를 `KAKAO_REST_API_KEY` 환경변수(GitHub에서는 저장소 Secrets)에 넣으면,
  사전에 없는 장소를 카카오 로컬 검색으로 찾아 `data/geocode_cache.json`에 저장합니다. 잘못 찾은 곳은 그 파일에서 지우거나 값을 `false`로 바꾸세요.

## GitHub에서 매일 자동 실행

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `/docs`.
3. Settings → Actions → General → Workflow permissions: **Read and write permissions**.
4. Actions 탭 → `daily report` → **Run workflow**로 한 번 돌려 봅니다. 이후 매일 09:00(KST)에 자동으로 돌아갑니다.

## 주의

- 소모임 페이지 구조가 바뀌면 수집이 멈출 수 있습니다. `climbing_report/somoim.py`의 파서를 고치면 됩니다.
- 공개 페이지라도 소모임 이용약관의 자동 수집 관련 조항을 확인하고, 요청 간격과 횟수는 지금처럼 보수적으로 유지하세요.
- 참석 인원은 소모임 '참석 신청' 기준이라 실제 인원과 다를 수 있습니다.
